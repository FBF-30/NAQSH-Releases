المثبت الجديد يعرض الترحيب والمسار قبل التثبيت، ثم تقدمًا وشاشة اكتمال وتشغيلًا اختياريًا. الافتراضي لكل مستخدم `%LOCALAPPDATA%\NAQSH`؛ المسار المخصص القابل للكتابة محفوظ عند الترقية. البيانات مستقلة في `%LOCALAPPDATA%\NAQSH.UserData`. البرنامج يستخدم الأسود والرمادي والعنابي كتفاصيل، بعناوين عربية أوضح وأيقونة جديدة وحفظ للتنويه وإغلاق Discord.

**Discord Live Membership Verification: Pending Integration.** المجتمع يفتح للانضمام فقط؛ Application وBackend HTTPS إنتاجي لم يجهزا بعد. تفتح واجهة نَقْش والمكتبة والإعدادات والتحديثات، وتبقى أدوات العضوية وراء تحقق صحيح. لا secrets في التطبيق؛ المُثبّت غير موقّع رقميًا.
